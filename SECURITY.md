# Security policy

yt-view-bot runs headless browser contexts and reads a proxy pool from disk.
If you find a security issue (leaked proxy credentials, session hijack in
the dispatcher, unsafe deserialization), please email the maintainer
privately instead of opening a public issue.

## Supported versions

| version | supported |
|---------|-----------|
| 0.6.x   | yes       |
| <0.6    | no        |

## Out of scope

- Reports about YouTube detecting the bot — that's expected behavior.
- Proxies you supplied yourself being low quality.
- Feature requests for CAPTCHA solving (not shipped, not planned).
